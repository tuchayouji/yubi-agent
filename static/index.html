Web UI 用法

  • 生成：输入主题和要求，点击生成文章
  • 改写：粘贴原文，选择改写指令
  • 对比：同一主题，对比基础版和驭笔版输出

CLI 命令

# 生成文章
python main.py generate \
  -t "主题" -r "要求"
# 改写文章
python main.py rewrite \
  -o "原文" -i "润色"
# 对比
python main.py compare \
  -t "主题" -r "500字"

六大组件

  • ① 行为约束：身份/格式/边界规则
